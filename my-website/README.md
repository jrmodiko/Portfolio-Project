This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with My browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-My-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

How Each Page Supports My Full‑Stack Developer Goal
1. Home Page — First Impression & Full‑Stack Branding
Supports My goal by:
Presenting a clean, responsive UI (frontend skill)
Showing a professional headline like “Full‑Stack Developer”
Demonstrating performance optimization (fast load, compressed assets)
Using routing, components, or templates (React, Vue, Node, PHP, etc.)
This page proves you understand frontend architecture and UX.

2. About Page — My Story, Skills & Tech Stack
Supports My goal by:
Listing frontend + backend skills (HTML, CSS, JS, React, Node, SQL, APIs)
Explaining My career goal (full‑stack development)
Showing My understanding of software development principles
Demonstrating structured content and clean layout
This page shows you can communicate My technical identity clearly.

3. Projects Page — Core Evidence of Full‑Stack Ability
This is the most important page. It supports My goal by:
Displaying full‑stack projects (frontend + backend + database)
Showing GitHub links, live demos, screenshots
Explaining architecture (APIs, routing, authentication, CRUD)
Demonstrating problem-solving and real-world application
Highlighting technologies used and why
Recruiters and clients judge My ability mainly from this page.

4. Contact Page — Backend Integration & Professionalism
Supports My goal by:
Using a backend service (Node, PHP, Firebase, etc.) to send messages
Implementing form validation (security + UX)
Showing you understand HTTP requests, APIs, and data handling
Demonstrating secure practices (HTTPS, sanitization, error handling)
This page proves you can build functional backend features.
